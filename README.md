# zip-merger

複数のZIPファイルをアップロードすると、各ZIP内に含まれるPDFファイルをすべて抽出し、1つのPDFファイルに結合してダウンロードできる静的サイトです。

- [JSZip](https://stuk.github.io/jszip/) でZIPを展開
- [pdf-lib](https://pdf-lib.js.org/) でPDFを結合
- サーバー不要、クライアントサイドのみで完結（アップロードしたファイルは外部に送信されません）
- ドラッグ&ドロップ対応
- 結合順序: すべてのZIPから展開したPDFを1つのフォルダにまとめたものとして扱い、ZIPの区別なくファイル名順で結合
- ZIP内のPDF以外のファイルは無視されます

## 使い方

1. `index.html` をブラウザで開く、またはGitHub Pagesで公開する
2. ZIPファイルをドラッグ&ドロップ、またはクリックして選択
3. 「PDFを結合してダウンロード」をクリック

## GitHub Pagesへのデプロイ

このリポジトリのSettings > Pagesで、公開元をルート (`/`) に設定してください。
