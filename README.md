# zip-merger

複数のZIPファイルをアップロードすると、各ZIP内に含まれるPDFファイルをすべて抽出し、ZIPの区別なく1つのフォルダにまとめた状態（1つのZIP）でダウンロードできる静的サイトです。PDFファイル自体は結合されず、個別のファイルのままです。

- [JSZip](https://stuk.github.io/jszip/) でZIPの展開・生成を行う
- サーバー不要、クライアントサイドのみで完結（アップロードしたファイルは外部に送信されません）
- ドラッグ&ドロップ対応
- 並び順: すべてのZIPから展開したPDFを1つのフォルダにまとめたものとして扱い、ZIPの区別なくファイル名順に並べる
- ZIP内のPDF以外のファイルは無視されます
- 同名のPDFファイルが複数のZIPに存在する場合は `ファイル名_2.pdf` のように連番を付けて衝突を回避します

## 使い方

1. `index.html` をブラウザで開く、またはGitHub Pagesで公開する
2. ZIPファイルをドラッグ&ドロップ、またはクリックして選択
3. 「PDFをまとめてダウンロード」をクリックすると `merged_pdfs.zip` がダウンロードされます

## GitHub Pagesへのデプロイ

このリポジトリのSettings > Pagesで、公開元をルート (`/`) に設定してください。
